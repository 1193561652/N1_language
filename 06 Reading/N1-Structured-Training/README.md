# JLPT N1 结构化阅读训练

本目录是 N1 阅读长期训练的持久化状态库。后续开始训练前，按以下顺序读取：

1. `CURRENT_STATE.md`：当前等级、弱点和下一步；
2. `TRAINING_PROTOCOL.md`：训练方法、升级标准和纠错规则；
3. `ERROR_LOG.md`：已经确认的错误机制；
4. `SESSION_LOG.md`：历次训练与测试证据。

## 更新规则

- 等级只由升级测试结果改变，不按日期或训练次数自动升级。
- 每轮回答后，先诊断错误类型，再决定下一组内容。
- 每完成一轮训练，更新 `CURRENT_STATE.md`，并向 `SESSION_LOG.md` 追加记录。
- 出现新的、可复现的错误机制时，向 `ERROR_LOG.md` 追加记录。
- 不覆盖历史记录；修正旧结论时，追加带日期的新记录并注明替代关系。
- 后续测试发现底层能力退化时，可以暂时返回前一级修复。
