# 项目信息

## 项目目标

本项目用于建立可长期维护的 JLPT N1 学习与真题系统，覆盖课程、词汇、搭配、语法、听力、阅读、语料、真题、复习和练习。当前最完整的可运行产物是根目录的离线真题答题页面。

## 当前离线真题范围

| 数据来源 | 期次 | 作用 |
| --- | --- | --- |
| 烧饼日语 | 2010.07–2022.12 | 早期结构化真题、图片和听力资源 |
| JLPT4YOU | 2023.07–2024.12 | 新增结构化真题、逐题听力和媒体资源 |
| 本地 PDF→Markdown | 2025.07、2025.12 | 从本地原始 PDF 与答案资料补充最新期次 |

统一题库目前包含 31 个期次、3,182 个作答点。答题界面将文字与词汇合并展示；底层仍按文字、词汇、语法、阅读、听力五科组织。2025 年听力使用每期整场 MP3，入口位于该期听力第一题。2025.12 向前十期已有逐题解析，来源解析经过答案和文本质量检查，不合格或缺失部分使用生成解析补齐。

## 数据层级

```text
原始资源
  library2 / 根目录历史 PDF
        ↓ OCR、视觉识别、PDF→Markdown
转换产物
  output
        ↓ 清洗、解析、结构化
站点抓取数据
  Shaobing Japanese / JLPT4YOU
        ↓ 合并构建
离线应用
  offline-exam-tool → 根目录 index.html
```

## 安全与本地状态

- `Shaobing Japanese\.sbry_auth.dpapi` 是本机加密的认证材料，不属于普通题库数据。
- 不在 `.agent`、README、日志或代码中记录账号、密码、Cookie、令牌明文。
- 项目启动模式下，每次提交会写入 `offline-exam-tool\history\records` 的独立 JSON；浏览器 `localStorage`（键名 `sbry-n1-offline-history-v1`）作为缓存。
- 直接双击打开与 `http://localhost:8765/` 打开属于不同浏览器存储空间；迁移记录应使用页面中的导出/导入功能。
