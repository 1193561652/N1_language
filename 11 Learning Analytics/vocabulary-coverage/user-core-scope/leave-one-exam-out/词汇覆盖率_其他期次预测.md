# 词汇覆盖率：用其他期次预测目标期次

采用留一期检验：31期（2010.07—2025.12），每次整期排除，用其余30期、750题建立共享词库，评价目标期25题。累计775题。允许参考目标期之前及之后的试题。不是按时间先后预测。

## 收词与模型口径

问题1、3：题干标出的词与全部选项；问题2、4：全部选项，不加入其他题干词。问题4收录选项例句中的实词。不同题型共享词库，词形作归一化。问题1错误读音仅在映射确认为真实词时入库，无法确认的伪读音不算独立词。

直接覆盖率指当前题的目标词是否能在参考词库中找到，不等于整题掌握。条件期望答对率假设已知词能正确运用、已知错误选项能无误排除，剩余选项均匀猜测。问题3须先认识题干标词才能排除，直接答对还要求认识正确选项；问题4假设认识目标词即可辨别用法。问题2暂不评估题干理解。因而该期望是条件模型结果，不是实测正确率或保证。

## 敏感性与对照

若额外学习读音选项映射中的多种常见同音词，直接覆盖率变为37.3%，模型期望变为55.4%。这是读音词义映射假设的差别，不是置信区间；映射并非所有可能词义的穷尽词典。

只看最近10期作为测试题、仍各用其他30期建库：直接覆盖36.0%，条件期望53.4%。此前仅用更早期次时，相同250题为35.2%、51.7%；新口径分别提高0.8、1.7个百分点。

可作为下一次考试的历史参照：直接词项覆盖约36%—37%，理想排除模型约54%—55%。留一期检验使用30期，真正下次考试可学习现有31期；不能将本检验结果直接当作下一次的准确概率，也未给出额外一期带来的收益。

## 核验

已检查两种映射情景各775题唯一、每题参考30期且不含目标期、全部索引来源属于参考期；相对于同源旧口径每题分数均未下降，最新一期结果完全一致；总计与题型权重计算一致。原始试题未修改。逐题结果见 question-scores.csv，完整来源与假设见 results.json。
