# 按用户指定核心范围重算覆盖率与排除模型

日期：2026-09-29。数据：2010.07—2025.12，31期775题。全程逐期预测，只使用此前期次。

## 学习词库范围

- 問題1：题干标词、正确读音，以及假名选项对应的真实词。错误拼读不作为词学习；未核实或未归并的候选不给覆盖／排除加分。
- 問題2：四个选项的词或表达。
- 問題3：题干标词、四个选项的词或表达。
- 問題4：四个选项句中的实词，包括其反复出现的目标词；不加入题干正文。
- 各问题共用历史词库，其他题干背景词均不入库。問題2、4不另扣当前题干理解分。

## 假名归并范围

新增 tools/reading_option_lexemes.tsv 将常见真实读音选项归并到词形。正确选项直接用本题标词还原。单一对应版本不把含多个候选汉字写法的假名项扩成额外词条；另算将列出的常见同音对应都学习的敏感性版本。多对应不能证明原题意指其中每一个词，不能当作确定的覆盖证据。未匹配项未全部证明为伪词；尤其罕见真实词可能漏计。词形还原及汉字／假名异写仍有误差。

## 排除模型的条件

- 問題1：目标词已掌握则计1；否则仅对可还原的真实词选项检查是否以前学过，并假设这些已知错误项可以有效排除。假名同音歧义使这个假设不能从词汇熟悉度直接得到保证。未知目标即随机猜的无排除对照也保留。
- 問題2：正确选项已掌握则计1；否则已知错误项假设可排除。默认当前句意足以判断，不因题干陌生词另扣分。
- 問題3：目标词和正确替换表达都已掌握计1；目标词已知但正确选项未知时，已知错误项假设可排除；目标词未知时不因认识选项就自动排除，计1/4。
- 問題4：目标词已掌握时假设义项、搭配与对象限制全部掌握，计1；未知计1/4。没有将认识整句背景词直接算成选对。
- 剩余m个选项按1/m；所有排除假设正确。这是有条件的理想模型，不是观察到的考生排除行为，更不是实际考试正确率保证。
- 不给未见词的构词、音读规律或其他推理额外加分；因此也不是任何学习者的能力上界。

若問題1不计可疑排除收益，其他题保持同样假设，最近10期整科模型为50.9%，而非51.7%。这使读音排除的不确定性可见。

## 与旧结果的差异

旧结果有的使用全部题干背景词、有的没有还原問題1的真实假名选项。本次同时删除背景题干并补充读音选项的词形对应；不能只把变化归因于排除法，旧结果不再作为此口径的主结论。

逐题目标、选项熟悉状态、词形归并、历史首次出处和两种排除分数均保存于 results.json；同音歧义敏感性也包含其中。
