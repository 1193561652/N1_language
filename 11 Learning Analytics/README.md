# N1 学习分析档案

本目录保存个人答题分析与能力发展记录。原始作答记录仍以
`offline-exam-tool/history/records/*.json` 为唯一事实来源；这里保存从原始记录派生出的长期状态。

## 文件结构

- `current-ability.md`：给人阅读的最新能力画像。
- `ability-profile.json`：可继续计算和更新的结构化能力状态。
- `state.json`：已经纳入分析的原始记录 ID，防止重复统计。
- `daily/YYYY-MM-DD.md`：按答题日期生成的当日分析和简报。
- `snapshots/YYYY-MM-DD.json`：当日结束时的能力快照。
- `development-history.md`：能力变化、重要证据和判断修订的时间线。
- `plans/current-plan.md`：根据最新证据制定的短期计划。

## 后续更新规则

1. 读取全部原始记录，以记录内的 `id` 去重，以文件名中的本地提交日期归档。
2. 区分“总题数正确率”“已作答正确率”和“完成率”；未作答不直接当作知识性错误。
3. 成绩按科目、大题类型、期次统计；诊断主体按考点组织。同一考点跨题型合并，同一题允许标注多个考点。
4. 每个有新作答的日期更新当日简报、当前画像、结构化状态、快照、发展履历和当前计划。
5. 历史快照只追加不覆盖。当前画像允许随着新证据修订。
6. 原始记录若被修正，须在发展履历中留下修订说明。
7. 排序题分别保存星号得分与四片段完整顺序；解析必须说明固定连接、助词支配、修饰关系以及错误顺序为何不成立。
8. 当用户未填写作答理由时，应明确标注“误区为反推”；不得把推测当作用户的真实理解。
9. 语法分析须映射《新完全マスター文法 日本語能力試験N1》的“部—课—条目”。教材目录有精确形式时标为“精确条目”；没有时只标“对应能力章节”，不得编造条目或页码。网络目录来源与映射规则保存在`references/shinkanzen-master-n1-grammar-map.md`。

## 当前题型口径

- 文字・词汇问题 1：汉字读音
- 文字・词汇问题 2：语境选词
- 文字・词汇问题 3：近义改写
- 文字・词汇问题 4：词语用法
- 语法问题 5：句子语法
- 语法问题 6：句子排序
- 语法问题 7：篇章语法

题型口径只用于统计，不作为主要诊断目录。长期能力画像优先追踪以下考点簇：汉字读音映射、词义边界与搭配、敬语主体和授受视角、让步/程度/条件功能、时体与说话人立场、篇章衔接、关系从句与修饰依存、固定句型连接块。
