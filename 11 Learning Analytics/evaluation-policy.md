# 答题与标注评价规范

制定日期：2026-09-29。依据用户要求：分析最近一次答题、全部标注的准确性、未标注处是否需要补注，并结合历史答题记录，按“N1完全掌握”的目标评价。后续分析默认使用本规范。

## 一、评价目标与证据边界

分别评价以下维度，不用单次选择题成绩替代整体掌握程度：

1. **作答准确性**：本次是否选对、完成情况，以及相对历史的变化。
2. **标注准确性**：写出的字词对应、中文释义或排除理由是否成立。
3. **辨析与应用**：能否区分重要近音、近义词，理解词形、搭配、对象限制及语境功能。
4. **主动提取与迁移**：能否脱离选项读出、解释，并在新题或新语境中应用。
5. **间隔保持**：纠正后是否隔一段时间仍能稳定回答。
6. **整体N1能力**：分别检查文字词汇、语法、阅读、听力的证据与缺口。

“N1完全掌握”是本学习档案的严格教学目标，不是官方定义的满分线，也不表示必须知道所有罕见义项或写出所有日文汉字。官方能力范围以[JLPT能力标准](https://jlpt.jp/sp/e/about/levelsummary.html)为参照；《新完全マスター》用于教材章节定位，不与掌握程度评分混为一谈。

## 二、中文输入条件下的标注判定

**用户只能输入中文。汉字基本对应，或中文义项成立，即算对。**

- 不因简繁、中文替代字、日文表记、送假名缺失而扣分。
- 允许单字或简短中文速记；不要求每条标注写成完整词条。
- 例如「炼→練る」「里切→裏切る」「念→唸る」「贿→賄う」「愈→癒す」「恼→悩む」，在对应选项中均可认可。
- 「操作→扱う」「清醒→冴える」「回溯→辿る」等真实义项成立时算对，不因没有列全义项而判错。
- 基本汉字一致不代表任意形近字都能对应。必须核对具体假名、词形及标注上下文；若字形关联与中文意思可能冲突，说明解释边界，不擅自认定用户持有错误词义。

使用三种证据状态：

| 状态 | 判定条件 | 处理方式 |
|---|---|---|
| 正确／可接受 | 汉字基本对应、中文义项或理由成立 | 算对；必要的词义扩展另列，不作为扣分 |
| 错误 | 明确对应到另一个词，或意思、语法功能、排除理由不成立 | 指出错在哪里，给出正确对应及易混词 |
| 待核实 | 标注确实存在无法消除的歧义，证据不足 | 不强行判对错；说明缺少什么证据 |

例如「からかって→络」「せめる→急」「あやした→育」「あきなって→谢」属于词本身错配，需要纠正，不属于中文输入造成的表记差异。

假名干扰项可能对应多个汉字。只要用户给出的对应本身成立，不要求该干扰项的词义也能代入题干；若用户明确在解释题干语境，则须检查语境义。正确标注只证明所写内容成立，不自动证明全部义项、搭配和长期保持已掌握。

## 三、未标注处是否应该补

**空白不等于不会，也不等于已掌握。过去写错、这次留空，不足以证明改正；过去写对、这次留空，也不能判定遗忘。**

逐项结合历史证据划分优先级：

| 优先级 | 典型情况 | 建议 |
|---|---|---|
| 优先补 | 曾误选、误标、反复混淆；缺少纠正证据；关键近义关系尚未区分 | 补中文词义、对比或读音线索，并复测 |
| 建议补一次 | 实际常用词或重要干扰项，尚无充分独立辨析证据 | 补核心义与必要区别；若能准确口述，可不重复写 |
| 复用已有证据 | 历史标注正确，或本次另一题已正确标出同一词 | 引用已有证据，检查能否迁移；不要求机械重写 |
| 可不标 | 明显不符合题面的错误读音，或已充分验证且无相反证据 | 无需强配汉字、扩展偏僻词或每次重复标注 |

正确项与干扰项分别审查。对首次纠正、反复错或回退的正确项，优先要求无选项提取；对多次保持正确的项目，不要求每轮抄写。用户可写中文解释、口述读音或复制假名，不以输入法能力评估日语能力。

## 四、历史对照方法

- 读取原始记录，按记录ID去重，以提交时间确定最新一次；按本地时区整理日期。
- 以题目ID匹配同题，以词汇或考点补充跨题型证据。遇到历史ID格式变化，核对来源、题干和选项后再关联，不只靠题号。
- 区分首次作答、熟题复测、同一题池重排、新语境或新题迁移。核对题目集合后，才能说“同一套题”。
- 分开记录“首次纠正”“连续纠正”“多次保持”“正确后回退”“反复未纠正”。相同正确率下，证据强弱可能不同。
- 同时追踪主答案与干扰项标注；主答案一直正确，也可能发生标注回退。
- 引用具体日期、原标注、误选与正确对应。用户写出的理由是直接证据；仅凭错误选项推测的机制必须标为“反推”。不得把“本轮无理由”扩大成“全部历史无理由”。
- 不以一次答对证明长期稳定，也不武断认定熟题高分只来自背答案。用主动提取、新语境和间隔复测验证。
- 本轮未测试的历史短板保留为“尚无新增纠正证据”；不因另一科满分自动上调。无阅读或听力记录表示证据不足，不等于不会。

## 五、统计口径

每份报告至少核对：作答数、正确数、完成率、用时、题目理由数、选项标注数、提前查看答案情况及重复题范围。

- 分开报告总题数正确率、已作答正确率、完成率；未作答不直接当作知识性错误。
- 标注正确率与答题正确率分开。存在待核实项时，列明数量；如计算已判定标注正确率，使用“正确÷（正确＋错误）”，明确未包含待核实项。
- 正确项标注、干扰项标注分别计数；空白干扰项数＝实际干扰项总数－已标注干扰项数，不能减去所有标注数。
- 累计作答次数与不同题目数分开；重复出现的标注也不等于不同词汇数量。
- 总耗时包括输入标注、停顿等，不直接当作纯识别速度；无逐条时间戳时，不断言标注写于选答案之前。
- 对疑似试用、异常或历史待核查记录保留说明，不悄悄删除或纳入。必要时并列全量口径与既有有效口径。
- 不把练习正确率换算成JLPT官方分数。

## 六、完全掌握的评价与训练建议

对于有足够证据的考点，检查是否同时满足：

1. 能脱离选项主动提取读音、核心义或语法功能。
2. 能准确排除重要干扰项，说明必要的词义边界、搭配或结构关系。
3. 能在未见题或新语境中应用，而非仅在原题中选对。
4. 经过间隔复测仍保持，不再反复出现相同混淆。

每个维度分别给出“本次达标／已有保持证据／尚未掌握／尚未验证”等结论，并说明依据；不将证据不足与确认不会混为一谈。整体N1评价还必须覆盖阅读和听力。

阶段训练可以使用“20题至少19题正确、顽固混淆全对”等明确目标，但须说明这是训练门槛，不能据一次小样本宣告完全掌握。间隔复测日期属于建议；除非用户另行要求，不自动创建提醒。

语法诊断继续按《新完全マスター文法N1》的“部—课—条目”定位。无精确条目时，只写“对应能力章节”，不编造条目或页码；依据见[章节映射基准](references/shinkanzen-master-n1-grammar-map.md)。

## 七、报告与档案维护

每次完整分析应包含：

1. 最新记录概况与总体结论。
2. 与历史相比的进步、回退及未验证之处。
3. 全部已写标注的逐项核对，而不只检查错题。
4. 全部未标注选项的补注判断、理由和建议内容。
5. 按掌握维度评价，并指出整体N1尚缺哪些证据。
6. 少量有针对性的下一步任务，优先处理反复错误与关键辨析。

主报告突出重点，完整逐项审查可作为链接附件保存。保留题目ID、原选项、原标注及来源记录，以便复核。遇到不确定读音、义项或表记，查可信辞典或语料后再判，不凭直觉把真实词义判错。

按[档案更新规则](README.md)维护当日报告、当前画像、结构化状态、快照、发展履历与训练计划。原始答题记录和用户标注不因分析而改写。历史快照不覆盖；判定规则或旧结论修订须记录原因。评分尺度改变后，旧数据若未按新尺度重评，不直接比较前后标注正确率。
