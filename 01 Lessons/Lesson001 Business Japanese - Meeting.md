# Lesson001 Business Japanese - Meeting

Status: v0.1 template lesson  
System: N1 Language System  
Scene: Business Japanese / Meeting  
Goal: 能听懂、读懂并主动组织一次基础商务会议相关表达, 同时连接到 N1 的词汇、文法、阅读和听力考点。

## ① Scene

会议不是单纯的「話す」, 而是围绕一个共同事项完成四个动作:

1. 共有する: 共享信息
2. 確認する: 确认事实、安排、资料、责任
3. 調整する: 调整时间、意见、资源
4. 決定する: 形成决定或下一步行动

本课的核心情景:

- 会议前: 确认日程、发送资料、通知参加者
- 会议中: 说明议题、确认情况、提出意见、调整计划
- 会议后: 共享会议记录、确认负责人、推进下一步

Japanese Thinking:

日语商务表达常常避免直接命令, 更偏向「共同确认」「请对方判断」「把责任放在事项本身」。因此, 中文里的“你确认一下”在日语里经常变成:

- ご確認ください。
- ご確認いただけますでしょうか。
- 内容をご確認のうえ、ご連絡ください。

重点不是逐字翻译, 而是掌握“行动对象 + 行动方式 + 礼貌距离”。

## ② Core Vocabulary

### Vocabulary Card 001

確認（かくにん）

- 词性: 名詞 / する動詞
- 核心意义: 确认事实、内容、状态是否正确
- 高频程度: 高
- 来源:
  - JLPT 官方样题页面出现「確認」作为说明性用语
  - 用户上传 N1 历年真题库: 待 OCR 后统计具体出现次数
- 常见搭配:
  - 資料を確認する
  - 内容を確認する
  - 予定を確認する
  - 日程を確認する
  - メールを確認する
  - 担当者に確認する
- 教学例句:
  - 会議の前に、資料を確認しておいてください。
  - 日程を確認したうえで、改めてご連絡いたします。
- N1 连接:
  - 「確認したうえで」连接阅读中的条件和顺序关系。
  - 「確認せずに」连接听力中的失误原因。

### Vocabulary Card 002

会議（かいぎ）

- 词性: 名詞
- 核心意义: 多人围绕议题进行讨论、报告、决定的场合
- 高频程度: 高
- 来源:
  - 商务日语基础场景
  - 用户上传 N1 历年真题库: 待 OCR 后统计
- 常见搭配:
  - 会議を開く
  - 会議に参加する
  - 会議に出席する
  - 会議を欠席する
  - 会議で報告する
  - 会議の資料
  - 会議の議題
- 教学例句:
  - 午後の会議で、新しい計画について報告します。
  - 会議に出席できない場合は、事前にご連絡ください。
- N1 连接:
  - 听力常考“谁参加、谁负责、下一步做什么”。
  - 阅读常见于公司通知、邮件、议事录。

### Vocabulary Card 003

資料（しりょう）

- 词性: 名詞
- 核心意义: 用于说明、判断、参考的信息材料
- 高频程度: 高
- 来源:
  - JLPT 官方页面将官方题本称为「資料」
  - 用户上传 N1 历年真题库: 待 OCR 后统计
- 常见搭配:
  - 資料を作成する
  - 資料を配布する
  - 資料を確認する
  - 資料に目を通す
  - 参考資料
  - 会議資料
- 教学例句:
  - 会議資料に目を通してから参加してください。
  - 必要な資料を事前に共有いたします。
- N1 连接:
  - 「目を通す」是高频商务搭配, 不等于“看眼睛通过”, 而是“浏览、过目”。

### Vocabulary Card 004

調整（ちょうせい）

- 词性: 名詞 / する動詞
- 核心意义: 在多个条件之间做协调、调整
- 高频程度: 高
- 来源:
  - 商务会议与项目推进场景
  - 用户上传 N1 历年真题库: 待 OCR 后统计
- 常见搭配:
  - 日程を調整する
  - 時間を調整する
  - 意見を調整する
  - スケジュールを調整する
  - 関係者と調整する
- 教学例句:
  - 参加者の都合に合わせて、日程を調整します。
  - 関係部署と調整したうえで、結論を出します。
- N1 连接:
  - 「〜に合わせて」表示依据对象进行调整。
  - 「〜たうえで」表示完成前项后再进行后项。

### Vocabulary Card 005

議題（ぎだい）

- 词性: 名詞
- 核心意义: 会议中要讨论的主题
- 高频程度: 中高
- 来源:
  - 会议场景核心词
  - 用户上传 N1 历年真题库: 待 OCR 后统计
- 常见搭配:
  - 議題を決める
  - 議題に入る
  - 本日の議題
  - 次の議題
- 教学例句:
  - 本日の議題は、来月の販売計画についてです。
  - では、次の議題に移りたいと思います。
- N1 连接:
  - 阅读中常与「〜について」「〜をめぐって」连接。

## ④ Sentence Pattern

### Pattern 1: X について確認する

Function: 确认某个事项  
Formality: 中性到正式  

Examples:

- 会議の日程について確認したいのですが。
- 資料の内容について、いくつか確認させてください。
- 今後の進め方について確認しておきましょう。

Thinking:

「について」把话题先放出来, 再进行「確認する」。这比直接问对方更柔和。

### Pattern 2: X したうえで、Y する

Function: 完成 X 之后, 再进行 Y  
JLPT Connection: N2-N1 阅读和商务表达常见  

Examples:

- 内容を確認したうえで、ご連絡いたします。
- 関係者と調整したうえで、会議の日程を決めます。
- 資料に目を通したうえで、ご意見をお聞かせください。

Thinking:

「うえで」不是简单的“之后”, 而是“前项是后项的必要准备”。

### Pattern 3: X に関して / X に関する

Function: 关于某事项  
Register: 书面、商务、说明文  

Examples:

- 本日の会議では、新企画に関して話し合います。
- 会議に関する資料を添付いたします。
- 日程に関して変更がありました。

Thinking:

「に関して」比「について」更书面, 常用于通知、邮件、说明。

### Pattern 4: X に基づいて Y する

Function: 根据 X 进行判断或行动  
JLPT Connection: N1 说明文、新闻、报告常见  

Examples:

- 調査結果に基づいて、今後の方針を決定します。
- 会議での意見に基づいて、資料を修正しました。

Thinking:

「基づいて」强调依据, 常用于报告、决定、制度、数据。

## ⑤ Dialogue

Source status: Teaching rewrite. 目标是训练会议表达网络, 不是复刻真题。

A: お疲れさまです。明日の会議について、少し確認してもよろしいでしょうか。  
B: はい、お願いします。  
A: 会議資料は、今日中に共有される予定でしょうか。  
B: はい。午後三時までにメールでお送りします。  
A: ありがとうございます。資料に目を通したうえで、質問を整理しておきます。  
B: 助かります。明日は新しい計画に関して意見を伺いたいと思っています。  
A: 承知しました。関係者とも事前に確認しておきます。  
B: よろしくお願いします。

Key expressions:

- 少し確認してもよろしいでしょうか。
- 今日中に共有される予定でしょうか。
- 資料に目を通したうえで
- 新しい計画に関して
- 事前に確認しておきます

## ⑥ Japanese Thinking

### 1. 先给话题, 再给动作

中文常说: 我想确认一下明天的会议。  
日语更自然: 明日の会議について、確認したいのですが。

结构:

Topic -> Action -> Soft ending

### 2. 商务日语常用「缓冲表达」

直接:

- 資料を送ってください。

更自然:

- 資料をお送りいただけますでしょうか。
- 資料をご共有いただけますと幸いです。

### 3. 动作常常和“准备状态”绑定

不是只说「見る」, 而是:

- 資料に目を通す
- 内容を確認する
- 質問を整理する
- 関係者と調整する

这些表达构成会议前的行动链。

## ⑦ Grammar

### Grammar 001: 〜について

- Meaning: 关于
- Function: 引出话题
- Register: 日常、商务、考试都常见
- Meeting usage:
  - 会議の日程について確認する
  - 新企画について話し合う

Practice:

- 明日の会議____確認したいことがあります。
- 新しい計画____意見を聞かせてください。

Answer:

- について
- について

### Grammar 002: 〜に関して / 〜に関する

- Meaning: 关于、涉及
- Function: 更书面地引出相关事项
- Register: 商务邮件、通知、说明文、N1 阅读
- Meeting usage:
  - 会議に関する資料
  - 日程に関して変更がある

Practice:

- 会議____資料を添付いたします。
- 日程____変更がありました。

Answer:

- に関する
- に関して

### Grammar 003: 〜たうえで

- Meaning: 在完成某动作之后, 再进行下一动作
- Function: 前项是后项的准备或条件
- Register: 商务、说明文、考试
- Meeting usage:
  - 資料を確認したうえで、質問する
  - 関係者と調整したうえで、決定する

Practice:

- 内容を確認した____、ご連絡いたします。
- 関係者と相談した____、改めてご報告します。

Answer:

- うえで
- うえで

### Grammar 004: 〜に基づいて

- Meaning: 根据
- Function: 表示判断、决定、行动的依据
- Register: 报告、新闻、说明文、N1 阅读
- Meeting usage:
  - 会議での意見に基づいて資料を修正する
  - 調査結果に基づいて方針を決める

Practice:

- 調査結果____、今後の方針を決定します。
- 会議の内容____、資料を修正してください。

Answer:

- に基づいて
- に基づいて

## ⑨ Practice

### 1. Collocation Practice

选择最自然的搭配。

1. 資料を（ A 見る / B 確認する / C 聞く ）
2. 日程を（ A 調整する / B 読む / C 食べる ）
3. 会議に（ A 出席する / B 作成する / C 修正する ）
4. 進捗を（ A 報告する / B 添付する / C 欠席する ）
5. 情報を（ A 共有する / B 欠席する / C 決定する ）

Answer:

1. B
2. A
3. A
4. A
5. A

### 2. Sentence Building

用指定表达造句。

1. 〜について確認する
2. 〜たうえで
3. 〜に関して
4. 〜に基づいて

Model answers:

1. 明日の会議について確認したいことがあります。
2. 資料を確認したうえで、質問を整理します。
3. 新しい計画に関して、意見を伺いたいです。
4. 会議での意見に基づいて、資料を修正します。

### 3. Instant Response

把中文意思转成自然日语。

1. 我想确认一下明天的会议。
2. 我会先看资料, 然后再联系您。
3. 关于日程有变更。
4. 根据会议内容修改资料。

Model answers:

1. 明日の会議について確認したいのですが。
2. 資料に目を通したうえで、改めてご連絡いたします。
3. 日程に関して変更がありました。
4. 会議の内容に基づいて資料を修正します。

### 4. Listening Mini Task

Script:

A: 明日の会議資料は、もう共有されていますか。  
B: まだです。今日の午後三時までにメールで送る予定です。  
A: わかりました。資料を確認したうえで、質問を整理しておきます。  
B: よろしくお願いします。

Question:

資料はいつ共有される予定ですか。

Answer:

今日の午後三時まで。

### 5. Reading Mini Task

Text:

明日の会議に関する資料を添付いたします。参加者の皆様は、事前に内容をご確認ください。会議では、新しい販売計画について意見交換を行います。資料を確認したうえで、ご質問がある場合は本日中にご連絡ください。

Questions:

1. 参加者は会議前に何をする必要がありますか。
2. 会議では何について話しますか。
3. 質問がある場合、いつまでに連絡しますか。

Answers:

1. 資料の内容を確認する。
2. 新しい販売計画について。
3. 本日中。

### 6. Integrated Practice

写一段 4 句的商务邮件, 必须包含:

- 会議
- 資料
- 確認
- 〜たうえで

Model:

明日の会議に関する資料を添付いたします。事前に内容をご確認ください。資料に目を通したうえで、ご質問がございましたら本日中にご連絡ください。どうぞよろしくお願いいたします。
