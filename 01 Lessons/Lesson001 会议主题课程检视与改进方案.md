# Lesson001 会议主题课程检视与改进方案

审阅对象：`Lesson001 会议主题学习计划 - 知识库版.md`

结论：当前版本已经具备“知识库驱动”的雏形，优于普通教材式列表；但它仍然偏索引和资料汇总，还没有完全形成一门可以循序执行的课程。更好的方案是改为：

真题簇 -> 场景任务 -> 语言网络 -> 输出能力 -> 回到真题检验

## 1. 当前版本的优点

| 优点 | 说明 |
|---|---|
| 有知识库依据 | 使用了 `output/N1考试知识库`，而不是凭空编课程 |
| 主题选择合理 | `会議` 与 `資料` 在知识库中命中高，适合作为商务日语第一主题 |
| 有真题入口 | 已列出 2010-2025 多个听力/真题页码 |
| 有词汇、搭配、语法表 | 方便查询和背诵 |
| 有由浅入深结构 | 从会前准备到会议执行，再到真题检验 |

## 2. 当前版本的主要问题

### 问题 1：真题入口多，但没有形成“真题簇”

现在列了很多年份和页码，但学习者仍然不知道先做哪几题、为什么这些题应该放在一起。

更好的做法：

把真题按任务聚类，而不是按年份罗列。

例如：

| 真题簇 | 代表题 | 训练能力 |
|---|---|---|
| 任务优先级 | 2021年12月 page 018、2016年12月 page 021 | 判断“首先做什么” |
| 资料修改 | 2018年12月 page 021、2024年07月 page 027 | 判断资料如何修改 |
| 日程/会议室 | 2010年07月 page 018、2017年07月 page 029 | 判断限制条件 |
| 会前打ち合わせ | 2012年12月 page 019-020、2018年12月 page 026 | 判断准备动作 |
| 即时应答 | 2019年07月 page 030、2020年12月 page 023 | 判断自然反应 |

### 问题 2：词汇表还不够“关系化”

现在词汇表是平面列表。对记忆有帮助，但对形成日语思维还不够。

更好的做法：

把词汇放进动作链。

```text
資料
  -> 資料を作成する
  -> 資料を送付する
  -> 資料に目を通す
  -> 資料を確認する
  -> 資料を修正する
  -> 資料を共有する
```

这样学习者记住的不是一个词，而是一条业务流程。

### 问题 3：语法表合理，但与真题簇连接还不够强

例如 `〜たうえで`、`〜に基づいて` 很适合会议主题，但课程还没有明确说明：

- 哪些真题在考“前后顺序”
- 哪些真题在考“依据关系”
- 哪些真题在考“让步/否定干扰”

更好的做法：

每个语法必须绑定一个听力判断功能。

| 语法 | 听力判断功能 | 会议例 |
|---|---|---|
| 〜たうえで | 前项完成后再做 | 资料先确认，再整理问题 |
| 〜に基づいて | 根据资料/意见修改 | 根据会议意见修改企画书 |
| 〜を踏まえて | 综合前情再行动 | 根据打ち合わせ制作企画书 |
| 〜次第 | 一确定马上联系 | 日程确定后通知相关人员 |

### 问题 4：缺少“产出任务”

当前课程有掌握标准，但中间缺少逐步产出。

更好的做法：

每个阶段必须产出一个小成果：

| 阶段 | 产出 |
|---|---|
| 会前准备 | 写 5 句会议确认表达 |
| 资料处理 | 写一段资料修改说明 |
| 日程调整 | 模拟一段会议延期电话 |
| 打ち合わせ | 复述一段听力中的任务链 |
| 会议执行 | 写 120 字会议纪要 |

### 问题 5：阅读部分弱于听力部分

知识库中的会议主题明显偏听力，但如果目标是完整掌握主题，应补上阅读路径：

- 通知
- 募集说明
- 会议资料
- 议事录
- 企画书说明
- 活动日程表

## 3. 更好的课程结构

建议把 Lesson001 改成 6 个 Unit，而不是 5 个 Level。

### Unit 1：会议前确认

目标：听懂和表达会议前的基本确认。

核心词：

- 会議
- 日程
- 予定
- 会議室
- 確認
- 連絡

核心搭配：

- 日程を確認する
- 会議室を予約する
- 日程を変更する
- 関係者に連絡する

真题簇：

- 2021年12月 听力 page 018
- 2010年12月 听力 page 025
- 2015年07月 听力 page 027

产出任务：

写一段会议延期通知。

### Unit 2：会议资料处理

目标：掌握资料的准备、确认、修改、共享。

核心词：

- 資料
- 企画書
- データ
- 修正
- 反映
- 確認

核心搭配：

- 資料に目を通す
- 資料を修正する
- データを反映させる
- 企画書を直す

真题簇：

- 2018年12月 听力 page 021
- 2024年07月 真题 page 027
- 2016年12月 听力 page 021
- 2020年12月 听力 page 023

产出任务：

写一段“根据会议意见修改资料”的说明。

### Unit 3：打ち合わせ与任务优先级

目标：判断多任务中“首先做什么”。

核心词：

- 打ち合わせ
- 企画書
- 情報
- 作成
- 担当
- 優先

核心搭配：

- 打ち合わせをする
- 打ち合わせを踏まえて
- 情報をまとめる
- 企画書を作成する

真题簇：

- 2012年12月 听力 page 019-020
- 2011年07月 听力 page 020
- 2018年12月 听力 page 022

产出任务：

把一段听力内容改写成“任务流程表”。

### Unit 4：会议执行与角色关系

目标：听懂会议中谁负责、谁汇报、谁决策。

核心词：

- 担当
- 報告
- 説明
- 進行役
- 議題
- 結論

核心搭配：

- 進捗を報告する
- 資料に基づいて説明する
- 議題を絞る
- 結論を出す

真题簇：

- 2015年12月 听力 page 022
- 2018年12月 听力 page 026
- 2022年12月 听力 page 021

产出任务：

做一段 1 分钟会议汇报。

### Unit 5：会议中的问题与调整

目标：听懂会议为什么开不好、为什么需要调整。

核心词：

- 議論
- 反論
- 意見
- 集約
- 効率化
- 調整

核心搭配：

- 意見が分かれる
- 議論が紛糾する
- 話が集約される
- 会議の効率化を図る

真题簇：

- 2020年12月 听力 page 022
- 2010年07月 听力 page 018

产出任务：

说明“为什么这个会议没有形成结论”。

### Unit 6：即时应答与会后跟进

目标：能在会议相关口语中做自然反应。

核心表达：

- あ、読んでおきます。
- 申し訳ありません。うっかりしていました。
- どこか間違っていたでしょうか。
- 承知しました。
- 確認いたします。

真题簇：

- 2019年07月 听力 page 030
- 2020年12月 听力 page 023
- 2010年12月 听力 page 027
- 2016年12月 听力 page 027

产出任务：

完成 20 组即时应答。

## 4. 推荐的新学习顺序

原顺序：

会前准备 -> 资料处理 -> 日程调整 -> 打ち合わせ -> 会议执行

建议改为：

1. 会前确认
2. 资料处理
3. 任务优先级
4. 会议执行
5. 问题与调整
6. 即时应答

理由：

- N1 听力最常考“接下来首先做什么”，所以任务优先级要提前。
- `資料` 是最高频会议相关核心物，不应只作为一个子项，而应成为一个独立 Unit。
- 即时应答不要太早学，应该放在最后，因为它依赖语气、上下文和隐含信息。

## 5. 更好的掌握标准

当前掌握标准偏概括。建议改成可测试标准：

| 能力 | 达标标准 |
|---|---|
| 词汇 | 能围绕 `資料` 说出 8 个动作 |
| 搭配 | 能默写 30 个会议搭配 |
| 语法 | 能用 8 个会议语法各造 2 句 |
| 听力 | 能完成 20 个会议相关真题入口复盘 |
| 阅读 | 能读懂会议通知/日程/资料说明 |
| 输出 | 能写会议延期通知、资料修正说明、会议纪要 |
| 日语思维 | 能用日语动作链解释“会前到会后” |

## 6. 最终建议

建议不要直接废弃当前课程，而是升级为两个文件：

1. `Lesson001 会议主题学习计划 - 知识库版.md`
   - 保留为索引和知识库证据文件。

2. `Lesson001 会议主题课程 - 执行版.md`
   - 新建为真正学习用课程。
   - 按 6 个 Unit 编排。
   - 每个 Unit 固定包含：
     - 场景目标
     - 核心词汇
     - 固定搭配
     - 语法逻辑
     - 真题簇
     - 输出任务
     - 复习卡

这样最稳：一个文件负责“证据与索引”，一个文件负责“学习与执行”。
