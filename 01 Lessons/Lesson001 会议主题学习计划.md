# Lesson001 会议主题学习计划

目标：从“能看懂会议相关表达”逐步推进到“能完整处理会议前、会议中、会议后相关听说读写任务”。

来源状态：

- 官方来源：JLPT 官方样题页面、JLPT 官方问题集页面。
- 公开语料扩展：厚生劳动省会议议事录、会议资料页、goo 国语辞书。
- 真题状态：项目中已上传 2010-07 到 2021-07 共 22 份 N1 真题 PDF，但当前尚未完成 OCR，因此不能精确列出每道历年真题的原文、页码和题号。

## 1. 整体逻辑

会议主题不是一个单词主题，而是一个“任务链”：

会前准备 -> 会议开始 -> 资料确认 -> 议题说明 -> 意见交换 -> 调整决定 -> 会后跟进

对应日语动作链：

日程を確認する -> 資料に目を通す -> 議題を確認する -> 内容を説明する -> 意見を交換する -> 方針を決定する -> 関係者に共有する

学习重点：

1. 先掌握动作：確認する、調整する、報告する、共有する、決定する。
2. 再掌握对象：日程、資料、内容、議題、進捗、方針、担当者。
3. 再掌握关系：誰が、何を、いつまでに、どの資料に基づいて、どう決定するか。
4. 最后连接 JLPT：听力里的“下一步做什么”、阅读里的“通知/会议记录/资料说明”、语法里的依据、顺序、关联。

## 6. 语法逻辑解释

### 〜について vs 〜に関して

两者都表示“关于”，但语感不同。

- 〜について：一般话题提示，口语和书面都可用。
- 〜に関して：更正式，常用于邮件、通知、会议资料。

学习顺序：

1. 会議について確認する
2. 会議に関してご連絡します
3. 会議に関する資料

### 〜たうえで

这个语法的核心不是“之后”，而是“前项是后项的必要准备”。

错误理解：看完资料之后联系。  
正确理解：只有先确认资料，后面的提问/联系/判断才有依据。

核心链条：

資料を確認する -> 質問を整理する -> 会議で確認する -> 決定事項を共有する

### 〜に基づいて

这个语法强调“依据”。会议主题里，它通常连接：

- 資料に基づいて説明する
- 意見に基づいて修正する
- 調査結果に基づいて決定する

它会把表达从“日常对话”推进到“N1 说明文/报告文”。

## 7. 会话关系解释

会议会话不是随意聊天，而是由角色和任务推动。

| 角色 | 常见动作 | 常见表达 |
|---|---|---|
| 司会 | 开始、切换议题、总结 | それでは始めます / 次の議題に移ります |
| 担当者 | 汇报、说明、回答 | 進捗をご報告します / 資料をご確認ください |
| 参加者 | 提问、确认、提出意见 | 一点確認してもよろしいでしょうか |
| 上司/决策者 | 判断、批准、决定 | この方針で進めましょう |
| 事務局 | 发送资料、安排日程、记录 | 資料を送付いたします / 日程を調整します |

会话推进逻辑：

1. 司会打开会议：本日の議題は〜です。
2. 担当者输入信息：資料に基づいて説明します。
3. 参加者确认：一点確認してもよろしいでしょうか。
4. 多方调整：参加者の都合に合わせて調整します。
5. 决策者决定：今後の方針を決定します。
6. 事務局跟进：決定事項を共有します。

## 9. 由浅入深的训练安排

### 第 1 周：会议前

目标：掌握日程、资料、参加者。

- 背诵：会議、資料、日程、予定、参加者、確認、調整。
- 搭配：資料を確認する、日程を調整する、会議に出席する。
- 语法：〜について、〜たうえで。
- 输出：写一段会议前确认邮件。

### 第 2 周：会议中

目标：掌握议题、说明、报告、意见交换。

- 背诵：議題、内容、進捗、報告、説明、意見。
- 搭配：議題に入る、内容を説明する、進捗を報告する、意見を交換する。
- 语法：〜に関して、〜として。
- 输出：做 1 分钟会议汇报。

### 第 3 周：会议后

目标：掌握决定、共享、修改、联系。

- 背诵：方針、決定、共有、修正、関係者、担当者。
- 搭配：方針を決定する、情報を共有する、資料を修正する。
- 语法：〜に基づいて、〜次第。
- 输出：写一段会后总结。

### 第 4 周：N1 化整合

目标：进入正式会议记录、通知、说明文。

- 阅读：政府会议议事录中的“日時、場所、出席者、議題、資料、議事”结构。
- 听力：训练“谁负责、什么时候做、下一步是什么”。
- 语法：〜をめぐって、〜において、〜にあたって。
- 输出：完成一套原创 N1 风格会议主题综合题。

## 10. 检验题

以下为原创检验题，用于在 OCR 历年真题前先检验学习结果。

### 题 1：搭配选择

会議の前に、参加者へ資料を（　　　）いたします。

1. 欠席
2. 送付
3. 決定
4. 出席

答案：2

### 题 2：语法选择

資料を確認した（　　　）、ご意見をお聞かせください。

1. うえで
2. ものの
3. ばかりに
4. にしては

答案：1

### 题 3：阅读理解

明日の会議に関する資料を添付いたします。参加者の皆様は、事前に内容をご確認ください。会議では、今後の販売方針について意見交換を行います。ご質問がある場合は、本日中に担当者までご連絡ください。

问题：参加者は会議前に何をする必要がありますか。

答案：資料の内容を確認する。

### 题 4：听力逻辑

A: 明日の会議資料はもう共有されていますか。  
B: まだです。今日の午後三時までに送付する予定です。  
A: わかりました。資料を確認したうえで、質問を整理しておきます。

问题：資料はいつ送付されますか。

答案：今日の午後三時まで。

### 题 5：N1 风格

会議での意見（　　　）、資料を修正することになった。

1. に基づいて
2. に反して
3. に限って
4. に先立って

答案：1
