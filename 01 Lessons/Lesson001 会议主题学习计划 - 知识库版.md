依据：

- 本地知识库：`output/N1考试知识库`
- 覆盖范围：31 个期次，2010年07月 到 2025年12月
- 页级 chunk：1401 个
- 听力原文：30 份
- 会议主题检索结果：`会議` 命中 188 个 chunk，`資料` 命中 189 个 chunk

本计划目标不是“学几个会议词”，而是把会议作为一个完整领域掌握：

会前准备 -> 会议执行 -> 资料/议题处理 -> 意见交换 -> 决定与修改 -> 会后共享

## 1. 会议主题的整体逻辑

会议主题在 N1 真题中主要不是考“会议是什么”，而是考你能不能听懂或读懂以下关系：

| 关系 | 核心问题 | 典型 N1 问法 |
|---|---|---|
| 时间关系 | 会议什么时候、是否变更 | まず何をしなければなりませんか |
| 资料关系 | 资料是否确认、修改、发送 | 資料をどのように直しますか |
| 任务关系 | 谁接下来做什么 | このあと何をしなければなりませんか |
| 角色关系 | 上司、部下、担当者、参加者 | 誰が何を担当しますか |
| 依据关系 | 根据会议/调查/意见修改 | 何に基づいて決定しますか |
| 结果关系 | 会议是否延期、决定、共享 | どうして延期しますか |

因此学习顺序应为：

1. 词汇：会議、資料、日程、確認、調整、報告、担当。
2. 搭配：資料を確認する、日程を調整する、会議に出席する。
3. 句型：〜について、〜に関して、〜たうえで、〜に基づいて。
4. 场景：会前准备、会中汇报、会后修改。
5. 真题检验：听力問題1、問題2、問題4；阅读信息检索。

## 5. 语法逻辑解释

### 〜について

逻辑：把一个事项放到桌面上，后面接“确认、说明、讨论、汇报”。

核心链：

会議について確認する -> 日程について説明する -> 方針について話し合う

### 〜に関して / 〜に関する

逻辑：不是简单“关于”，而是把某事项作为正式关联对象。适合邮件、通知、会议资料。

例：

- 会議に関する資料
- 日程に関して変更がある
- 新商品に関して報告する

### 〜たうえで

逻辑：前项不是普通时间顺序，而是后项成立的准备条件。

会议里常见：

資料を読む -> 質問を整理する  
内容を確認する -> 連絡する  
関係者と調整する -> 決定する

### 〜に基づいて

逻辑：依据来源明确。比“因为”更正式，常见于报告、会议、企画书。

会议里常见：

調査結果に基づいて決定する  
会議での意見に基づいて修正する  
資料に基づいて説明する

## 6. 会话关系图

| 角色 | 任务 | 常见表达 | 真题中常考点 |
|---|---|---|---|
| 上司 | 指示、确认、修改要求 | 確認したよ / 修正してくれる？ | 接下来先做什么 |
| 部下/社員 | 接受任务、说明困难 | 今、資料を作っています / 承知しました | 优先顺序 |
| 課長 | 判断资料是否合适 | この資料、直して | 修改方向 |
| 担当者 | 汇报/说明 | 進捗を報告します | 负责内容 |
| 事務局 | 会场、资料、日程 | 会議室の予約 / 資料のコピー | 准备工作 |
| 参加者 | 出席、确认、提问 | 一点確認してもよろしいですか | 会话反应 |

会议听力的隐藏逻辑：

1. 先听“已经完成的事”：会議室は予約済み、資料はコピー済み。
2. 再听“被否定的事”：それはもういい、そこは大丈夫。
3. 最后抓“真正要做的事”：先にお願い、今日中に、まず。

## 7. 由浅入深学习安排

### Level 1：会前准备

目标：听懂会议前要准备什么。

背诵：

- 会議、会議室、資料、日程、予定、確認、送付、コピー

搭配：

- 会議資料を送付する
- 資料を確認する
- 会議室を予約する
- 日程を変更する

真题检验：

- 2021年12月 听力 問題1 page 018：10 点会议延迟，先联系谁。
- 2010年12月 听力 問題3 page 025：会议日程变更与资料重新作成。
- 2015年12月 听力 問題1 page 019：会合资料、会议室预约、先读资料。

### Level 2：资料处理

目标：能判断资料要“看、改、发、复制、重做”。

背诵：

- 資料、企画書、説明、修正、データ、反映、確認

搭配：

- 資料に目を通す
- 資料を修正する
- データを反映させる
- 企画書を直す

真题检验：

- 2018年12月 听力 問題1 page 021：会议企画书中图表数据需更新。
- 2024年07月 听力 問題1 page 018 / 真题 page 027：会议资料的设计案如何修改。
- 2016年12月 听力 問題1 page 021：企画书确认后，优先修正用于打ち合わせ的资料。
- 2020年12月 听力 問題4 page 023：资料要在会议前“目を通す”。

### Level 3：日程与调整

目标：掌握会议时间、会议室、人数、条件调整。

背诵：

- 日程、予定、変更、調整、会議室、定員、延長、予約

搭配：

- 日程を変更する
- 日程を知らせる
- 会議室を予約する
- 時間をずらす

真题检验：

- 2010年07月 听力 問題1 page 018：会议效率指针，开始时间、会议时间、议题数量。
- 2017年07月 听力 問題4/5 page 029：会议室选择，人数、空间、机动性。
- 2015年07月 听力 問題4 page 027：会议予定表、开始时间和会議室空き。
- 2022年12月 听力 page 020：讲演会日程已确定，先通知毕业生。

### Level 4：打ち合わせ与企画

目标：能处理会前碰头、企画书、方案修改。

背诵：

- 打ち合わせ、企画書、検討、方針、対象、反映、明確

搭配：

- 打ち合わせをする
- 打ち合わせを踏まえて
- 企画書を作成する
- 調査結果を反映させる

真题检验：

- 2012年12月 听力 page 019/020：先整理信息，再基于打ち合わせ制作企画书。
- 2010年12月 听力 page 021：调查结果反映到企画书修正。
- 2017年07月 听力 page 021：企画会议后，追加采访对象。
- 2024年07月 听力 page 019：大学祭企画书修正，补充费用细节。

### Level 5：会议执行与意见整理

目标：听懂会议为什么开不好、怎样推进。

背诵：

- 議題、進行役、議論、反論、意見、結論、集約

搭配：

- 議題を絞る
- 会議を進める
- 意見をまとめる
- 結論を出す

真题检验：

- 2020年12月 听力 page 022：全体会议冗长，问题在于反论多但不提出解决方案。
- 2018年12月 听力 page 026：会前需要与会议进行役打ち合わせ。
- 2016年12月 听力 問題4 page 027：初めての会議の司会じゃあるまいし。

## 11. 掌握标准

你可以认为“会议主题”已基本掌握，当你能做到：

1. 看到 `会議 / 資料 / 日程 / 確認 / 調整 / 打ち合わせ / 企画書` 能立即说出 3 个搭配。
2. 听到会议场景，能判断“已经完成的事”和“接下来首先要做的事”。
3. 能用 `〜たうえで / 〜に基づいて / 〜を踏まえて / 〜次第` 组织会议相关句子。
4. 能回查上表至少 15 个真题入口，并说明每题考的是时间、资料、任务、角色还是结果。
5. 能写一封 120-180 字会议前通知邮件和一封会后资料修正通知。
