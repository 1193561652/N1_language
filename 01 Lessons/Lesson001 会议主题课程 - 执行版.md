# Lesson001 会议主题课程 - 执行版

定位：Business Japanese / Meeting  
目标：用 4 周掌握“会议”主题的核心词汇、搭配、语法、听力判断、阅读理解和基础输出。  
知识库依据：`output/N1考试知识库`，其中 `会議` 命中 188 个 chunk，`資料` 命中 189 个 chunk。

学习原则：

1. 不从单词开始，而从会议任务开始。
2. 每个词必须进入搭配。
3. 每个语法必须服务于听力/阅读判断。
4. 每个 Unit 都要有输出任务。
5. 最后回到真题簇检验。

## 总路线

```text
Unit 1 会前确认
  -> Unit 2 资料处理
  -> Unit 3 打ち合わせ与任务优先级
  -> Unit 4 会议执行与角色关系
  -> Unit 5 问题与调整
  -> Unit 6 即时应答与会后跟进
```

核心动作链：

```text
日程を確認する
  -> 資料を送付する
  -> 資料に目を通す
  -> 打ち合わせをする
  -> 進捗を報告する
  -> 意見をまとめる
  -> 資料を修正する
  -> 決定事項を共有する
```

## Unit 1 会前确认

### 场景目标

听懂和表达会议前的基础确认：时间、地点、会议室、是否变更、先联系谁。

| 词汇 | 读音 | 意义 | 学习重点 |
|---|---|---|---|
| 会議 | かいぎ | 会议 | 场景核心 |
| 会議室 | かいぎしつ | 会议室 | 地点与预约 |
| 日程 | にってい | 日程 | 日期安排 |
| 予定 | よてい | 预定、计划 | 原计划 |
| 変更 | へんこう | 变更 | 与日程搭配 |
| 確認 | かくにん | 确认 | 会前核心动作 |
| 連絡 | れんらく | 联系 | 通知相关人员 |
| 延長 | えんちょう | 延长 | 时间变化 |
| 予約 | よやく | 预约 | 会场/会议室 |
| 先方 | せんぽう | 对方公司/对方 | 商务关系 |

### 固定搭配

| 搭配 | 例句 | 逻辑 |

| 日程を確認する | 明日の会議の日程を確認したいのですが。 | 确定时间 |

| 会議室を予約する | 会議室はすでに予約してあります。 | 场地准备 |

| 関係者に知らせる | 日程が決まり次第、関係者に知らせます。 | 会前通知 |

### 语法逻辑

| 语法 | 逻辑 | 例句 |
|---|---|---|
| 〜について | 把话题提出 | 明日の会議について確認したいのですが。 |

## Unit 2 会议资料处理

### 场景目标

| 企画書を直す | 打ち合わせで使う企画書を直します。 | 会前修正 |

| 语法 | 逻辑 | 例句 |

## Unit 5 会议中的问题与调整

### 场景目标

| 異議 | いぎ | 异议 | 反对意见 |

| 効率化 | こうりつか | 提高效率 | 会议改善 |

| 絞る | しぼる | 缩小、限定 | 限定议题 |

### 固定搭配

| 搭配 | 例句 | 逻辑 |

| 语法 | 逻辑 | 例句 |
